# 真实粒子地球 · Accurate Particle Earth

一个纯前端、零外链的 **Three.js 3D 粒子视觉系统**。星球由数万颗圆形粒子构成，陆地轮廓来自 **Natural Earth 1:10m** 真实地理数据（world-atlas TopoJSON），不是程序噪声。

线上地址：<https://111qqq333www444.github.io/website/>

打开方式：必须通过 HTTP/HTTPS（直接双击 `file://` 会被 CORS 拦住本地数据）

```bash
python3 -m http.server 8000   # 然后访问 http://localhost:8000/
```

## 三、核心技术决策（踩过的坑）

### 1. 陆地判定：光栅化查表，而不是 `d3.geoContains`

| 方案 | 单次耗时 | 20 万采样点 |
| --- | --- | --- |
| `d3.geoContains`（land-10m，40.9 万顶点） | ≈ 39 ms | 约 2 小时，浏览器必然卡死 |
| canvas 光栅化 + O(1) 查表 | ≈ 0.0002 ms | 32 ms |

把真实几何按**等距圆柱投影**画进 `2048×1024` canvas（0.176°/px），再按 `(lon, lat) → 像素` 查表。数据源仍是 Natural Earth 真实几何。

> 额外发现：world-atlas 的 land-10m 环缠绕方向与 d3 的球面约定不一致，实测 `geoContains` 会把大西洋、几内亚湾、南太平洋也判成陆地（恒为 `true`）。所以这里不只是"更快"，是"更快且更准"。

### 2. 光栅化必须处理的两个坑

- **反经线 ±180° 拆分**：经度跳变 > 180° 的边会在展开图上拉出横贯画面的直线。做法是在跳变处切分环，并在对侧边缘补插值点。
- **`fill('evenodd')`**：正确处理内湖（里海、五大湖等），否则湖泊会被填成陆地。

### 3. 内部不能是空的

只画表面点壳会看到背面粒子穿透。做法是内部两层大软粒子填满：9 万颗 **Normal 混合**雾体（不透明度 0.17）+ 15 万颗 **Additive** 辉光雾（0.13），半径从 0.16R 一直填到 0.99R。

### 4. 外层"防护罩"要像雾，不能像实心球

两层叠加：2.8 万颗**大号软粒子**（1.02R ~ 1.22R，加色混合，不透明度 0.075）+ 一层**菲涅尔球壳**（BackSide + 加色，`pow(0.72 - dot(N, V), 3.2)`）。前者给雾感，后者给边缘轮廓。

### 5. 辉光只让太阳触发

`UnrealBloomPass(strength 0.45, radius 0.55, threshold 0.78)`，阈值调高后地球粒子与雾壳不会过曝，只有远处太阳核心与光晕起辉。

### 6. 依赖全部本地化

`vendor/` 下放 three.js、OrbitControls、后处理链、topojson-client、d3-geo、d3-array 与 `land-10m.json`（3.0 MB）。不依赖任何 CDN，断网也能跑；本地数据缺失时依次回退到在线 jsDelivr 源。

### 7. 网络健壮性

连接超时 10 秒（`AbortController`）· 4 秒无新数据即判定停滞重来 · 每个源失败重试 1 次再切换（本地 10m → 本地 110m → 在线 10m → 在线 110m）· 全部失败给明确错误 + 重试按钮，**绝不无限卡死**。

## 四、文件结构

```
index.html                 主页面（HTML + CSS + 着色器 + 全部逻辑，单文件可直接运行）
sw.js                      Service Worker：缓存 vendor 资源（CACHE = zjt-earth-v6）
vendor/
  land-10m.json            Natural Earth 1:10m 陆地 TopoJSON（3.0 MB）
  topojson-client.min.js   TopoJSON → GeoJSON
  d3-geo.min.js            球面几何（备用判定 / 校验）
  d3-array.min.js          d3-geo 依赖
  three/build/three.module.js
  three/examples/jsm/...   OrbitControls + EffectComposer / RenderPass / UnrealBloomPass / OutputPass
```

## 五、交互说明

- **拖动**旋转视角，**滚轮**缩放（与星球中心保持最小距离 3.2）
- **左下**显示可见粒子数 / 陆地采样数 / 数据源精度 / FPS
- **右下**全屏
- 转到星球背面可以看到远处的太阳
- 界面上没有任何参数控制面板，打开即最终效果
