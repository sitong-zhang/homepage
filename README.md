# 真实粒子地球 · Accurate Particle Earth

## 二、核心技术决策（踩过的坑）

### 1. 陆地判定：为什么必须用「光栅化查表」而不是 `d3.geoContains`

提示词原本要求用 `d3.geoContains` 逐点判定，实测不可行：

| 方案 | 单次耗时 | 20 万采样点 |
| --- | --- | --- |
| `d3.geoContains`（land-10m，40.9 万顶点） | ≈ 39 ms | **约 2 小时**，浏览器必然卡死 |
| canvas 光栅化 + O(1) 查表 | ≈ 0.0002 ms | **32 ms** |

光栅化方案：把真实几何按**等距圆柱投影**画进 `2048×1024` 的 canvas（0.176°/px），再按 `(lon, lat) → 像素` 查表。数据源仍是 Natural Earth 真实几何，轮廓一致。

> 额外发现：`world-atlas` 的 land-10m 环缠绕方向与 d3 的球面约定不一致，实测 `geoContains` 会把大西洋、几内亚湾、南太平洋也判成陆地（恒为 `true`）；而光栅化结果陆地占比 29.23%，与真实值吻合。所以这里不只是「更快」，而是「更快且更准」。

### 2. 光栅化必须处理的两个坑

- **反经线（±180°）拆分**：经度跳变 > 180° 的边会在展开图上拉出一条横贯画面的直线（视觉上的"赤道线"）。做法是在跳变处把环切成两条子路径，并在对侧边缘补插值点，保持形状闭合。
- **`evenodd` 填充**：正确处理内湖（里海、五大湖等），否则湖泊会被填成陆地。

### 3. 星球内部不能是空的

只画表面点壳会看到背面粒子穿透。做法是内部再放两层大软粒子：

- 6 万颗 **Normal 混合**雾体（`uOpacity 0.10`）→ 把内部"盖住"
- 12 万颗 **Additive 混合**辉光雾（`uOpacity 0.09`）→ 提供体积光感

### 4. 辉光只让太阳触发

`UnrealBloomPass(strength 0.45, radius 0.55, threshold 0.78)`，阈值调高后地球粒子不会过曝，只有远处的太阳核心与光晕起辉。

### 5. 依赖全部本地化

`vendor/` 下放 three.js、OrbitControls、后处理链、topojson-client、d3-geo、d3-array 与 `land-10m.json`（3.0 MB）。
好处：不依赖任何外部 CDN，断网也能跑；代价是仓库体积变大。即使本地数据缺失，代码仍会依次回退到在线 jsDelivr 源。

### 6. 网络健壮性

- 连接超时 **10 秒**（`AbortController`）
- 下载停滞检测：4 秒无新数据即中止重来
- 每个源失败自动重试 1 次，再切换下一个源（本地 10m → 本地 110m → 在线 10m → 在线 110m）
- 全部失败给出明确错误文案 + 重试按钮，**绝不无限卡死**

### 7. 必须用 HTTP/HTTPS 打开

直接双击 `file://` 打开时，浏览器 CORS 会拦截本地 `fetch`，页面会永远卡在加载。已内置协议检测提示，建议：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000/
```

## 三、文件结构

```
index.html                 主页面（HTML + CSS + 着色器 + 全部逻辑，单文件可直接运行）
sw.js                      Service Worker：缓存 vendor 资源（CACHE = zjt-earth-v6）
vendor/
  land-10m.json            Natural Earth 1:10m 陆地 TopoJSON（3.0 MB）
  land-110m.json           降级数据（若已放置）
  topojson-client.min.js   TopoJSON → GeoJSON
  d3-geo.min.js            球面几何（备用判定 / 校验）
  d3-array.min.js          d3-geo 依赖
  three/build/three.module.js
  three/examples/jsm/...   OrbitControls + EffectComposer / RenderPass / UnrealBloomPass / OutputPass
```

## 四、交互说明

- **拖动**：旋转视角；**滚轮**：缩放（与星球中心保持最小距离 3.2）
- **右上**：基础颜色、采样密度（6 万 ~ 26 万）、粒子大小、自转开关
- **左下**：可见粒子数 / 陆地采样数 / 数据源精度 / FPS
- **右下**：全屏
- 转到星球背面可以看到远处的太阳
